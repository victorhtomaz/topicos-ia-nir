<<<>><<>><<>><<>><<>><<>><<>>| Naming Convention |<<>><<>><<>><<>><<>><<>><<>>

Top-level folders should be descriptively named with a material or test type.

Within each test, the naming structure uses a combination of letter and 
numbers in groups of characters, as defined below, to describe a file.

                           Example: "A01_a100x000x000_00_00_N_01R.csv"
                                       |   |          |   | |  |
                               source —┘   |          |   | |  |
                            fiber content —┘          |   | |  | 
                                    batch/lot number —┘   | |  |
                                             form factor —┘ |  |
                                                instrument —┘  |
                                      replicate + data format —┘

where
    source = A for known provenance dyed samples 
                     {(AISE) color maintenance standard fabrics and custom 
                     dyed fabrics purchased from Testfabrics, inc. 
                     (West Pittston, PA)}
             B for known provenance undyed samples 
                     {fabric blends and custom fabrics purchased from 
                     Testfabrics, inc. (West Pittston, PA)}
             C for unknown provenance post-consumer samples 
                     {garments purchased from local secondhand store}
	     D for unknown provenance pre-consumer samples 
                     {production samples}

    sample content = a for cotton  
                     b for polyester (recycled polyester, PET)
                     c for synthetic polyamides (Nylon 6, Nylon 6,6)
                     d for acrylic
                     e for spandex
		     f for other polyurethanes [not currently used]
                     g for regenerated cellulosics (rayon, lyocell)
		     h for other natural cellulosics (hemp, flax) 
		     i for natural polyamides (wool, silk)
                     x for empty sets (N/A)
                   + 3 characters (000-100) for each fiber type's nominal 
                     blend percentage 

    batch/lot number = 2 characters (00-99), indicative of parent material 
                       source from which children (specimen) were derived
    form factor = 00 for woven
                  01 for knit
		  02 for nonwoven [not currently used]
	          03 for yarn [not currently used]
		  04 for fibers (shredded)
		  05 for fasteners (snaps, buttons, buckles, zippers) 
                         [not currently used]

    instrument = F for handheld NIR spectrometer (FabriTell)
                 G for time gated Raman spectrometer [not currently used]
                 N for benchtop NIR spectrometer (Nicolet)
    		 P for handheld Raman spectrometer [not currently used]
                 Q for standoff distance with Benchtop_N
                 S for handheld NIR spectrometer (Sortile)
                 T for stereo optical microscope
                 X for generic, placeholder

    replicate + data format = 2 characters (00-99), replicates of measurements 
                              on the same specimen 
                            + A for absorbance
                              C for color
                              M for mono
                              P for polarized
                              R for reflectance
                              S for scattering [not currently used]
                              T for transmittance [not currently used]
                              
                               
File naming convention augmentation for standoff distance
     Distance is encoded with replicate number: _XYZ
     where X = distance, Y = replicate, and Z = absorbance or reflectance
         3 = 0.5 cm
         4 = 1 cm
         5 = 2 cm
         6 = 3 cm
         7 = 4 cm
         8 = 8 cm

     Note: There is no 'zero distance' file for instrument Q. This is 
     equivalent to the file with the same sample ID under instrument N.
